A TypeScript program that writes a deadpan one-line comedy joke: an AI assistant told to act more human takes the instruction far too literally, and the punchline lands as three escalating office sins in one breath — ignored emails, blamed Wi-Fi, and a meeting deferred to next quarter. The joke works because the AI does not become charmingly human; it becomes exactly the coworker everyone already avoids.
